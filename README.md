## 🚀 Quick Launch & URLs

### 1. Local URL (Run on your machine)
You can view the site locally in any of the following ways:

#### Option A: One-Click Launcher (Windows)
Double-click [`start-server.bat`](file:///d:/New%20Location/OneDrive/Desktop/gopikaapp/start-server.bat). It automatically starts a local server and opens your browser at:
- **Local URL:** `http://localhost:8080/login.html`

#### Option B: Terminal Command
```bash
# Using Node http-server
npx http-server -p 8080 -c-1

# Or using Python
python -m http.server 8080
```
Then visit: **`http://localhost:8080/login.html`** or **`http://localhost:8080/index.html`**

#### Option C: Direct Browser Opening
Open [`login.html`](file:///d:/New%20Location/OneDrive/Desktop/gopikaapp/login.html) directly in Chrome, Edge, or Firefox.

## 🌐 Deploy to a Public URL on the Internet

To get a live public URL (e.g. `https://gopika-sadanand.vercel.app` or `https://gopika-portfolio.netlify.app`), choose one of the following free options:

### 1. Netlify Drop (Fastest - No Terminal Needed, 30 seconds)
1. Open your browser and go to [https://app.netlify.com/drop](https://app.netlify.com/drop) (free).
2. Drag and drop this folder (`gopikaapp`) into the upload box on Netlify.
3. Netlify will instantly generate a live public URL like:
   `https://gopika-sadanand-portfolio.netlify.app`

### 2. Vercel Deployment (Via CLI)
Run the following in PowerShell/CMD:
```powershell
npx vercel
```
Follow the 3 prompts (hit Enter to accept defaults). Vercel will build and output your production URL:
`https://gopika-sadanand.vercel.app`

### 3. GitHub Pages
1. Create a GitHub repository (e.g., `gopika-portfolio`).
2. Push this folder to the repository.
3. Go to **Settings > Pages > Branch: main / root** and click **Save**.
4. Your site will be published at:
   `https://<your-username>.github.io/gopika-portfolio/`
